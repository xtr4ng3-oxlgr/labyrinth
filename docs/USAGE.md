# Usage

Create a lab:

```bash
python labyrinth.py create suspicious-download
```

Open dashboard:

```bash
python labyrinth.py dashboard "labs/<lab-folder>"
```

Request hint:

```bash
python labyrinth.py hint "labs/<lab-folder>" --level 1
```

Reveal solution:

```bash
python labyrinth.py solution "labs/<lab-folder>"
```

Generate report:

```bash
python labyrinth.py report "labs/<lab-folder>"
```
