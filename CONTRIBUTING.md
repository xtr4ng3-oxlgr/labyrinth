# Contributing

Contributions should keep LABYRINTH safe, local and educational.

Good contributions:

- new synthetic scenarios,
- better report templates,
- clearer documentation,
- improved console output,
- safer packaging,
- additional hints and explanations.

Scenario rules:

- use fake domains,
- use fake tokens,
- never include real secrets,
- avoid instructions that require attacking external systems,
- keep artifacts safe to open as text.
